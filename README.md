# 文本切割工具

TXT 大文件智能分割工具，支持 100MB+ 文件高速处理。自动检测文件编码，优先在段落边界（空行）处切割，保持内容完整性。

## 功能特点

- **大文件支持** — 两遍逐行扫描，不将整个文件加载到内存，轻松处理 GB 级文件
- **智能编码检测** — 自动识别 UTF-8、UTF-8-SIG、GBK、GB2312、UTF-16 LE/BE、Latin-1 等编码
- **段落保护** — 优先在空行（段落边界）处分割，避免句子被截断
- **进度可视化** — 实时显示扫描进度和分割进度
- **内存友好** — 仅存储空行行号，不缓存文件内容

## 安装依赖

```bash
pip install chardet
```

> `chardet` 为可选依赖。未安装时程序会使用内置的启发式编码检测。

## 使用方法

```bash
python text_splitter.py
```

1. 点击 **浏览** 选择要切割的 TXT 文件
2. 设置输出目录（默认为桌面）
3. 设置分割份数
4. 编码默认为 **自动检测**，也可手动选择
5. 点击 **开始切割**

输出文件命名格式：`原文件名_1.txt`、`原文件名_2.txt`...

## 技术说明

- **第一遍扫描**：统计总行数 + 收集空行位置（1-based 行号集合）
- **分割点计算**：基于理想等分行号，向两侧搜索最近空行作为实际切割点
- **第二遍扫描**：按分割点逐行写入各输出文件，每个输出文件头部插入序号注释

## 支持的编码

| 编码 | 说明 |
|------|------|
| UTF-8 | 默认编码，自动检测 |
| UTF-8-SIG | 带 BOM 的 UTF-8 |
| GBK / GB2312 | 中文编码 |
| UTF-16 LE/BE | Unicode 小端/大端 |
| Latin-1 / ASCII | 西欧/纯英文 |

## 系统要求

- Python 3.8+
- 操作系统：Windows / macOS / Linux
